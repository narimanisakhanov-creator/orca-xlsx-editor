# Changelog

## 1.1.3

- No behaviour change: the editor and the worker are the ones shipped in 1.1.2.
- Documents what the two capabilities are used for. `SECURITY.md` names the host calls the
  `trusted-worker` makes, their handlers, the 4096-character cut and the fact that Enter is off by
  default; both READMEs gain an **Access and security** section that says the same in one screen. The
  1.1.2 release does not carry these docs: they landed after its tag, so this version is the first
  one a reviewer can read them in.

## 1.1.2

- Test workbooks are generated by `test/helpers/build-fixtures.mjs` instead of being committed, so the
  repository ships no binary files. The community directory refuses archives and executables; a
  `.xlsx` is a zip archive. `npm test` builds them on first use, byte-identically on every run.


## 1.1.1

- The hand-off popup opens leftwards from its button, so the editor frame no longer clips the
  preview of the text that will be sent.


## 1.1.0

Hand the table to an agent.

- New **В агента** control in the toolbar: pick an agent of the focused workspace, choose a Markdown
  table or TSV, read the exact text that will be sent, and pass it on. Nothing is sent without a
  press.
- The plugin now runs a Node worker (`trusted-worker`) with two capabilities: `agent:read` to list
  the workspace's agents and `terminal:send` to type into one terminal. Orca asks for both when the
  plugin is enabled, and every send is a single `terminal.sendText` call of at most 4096
  characters — text over that is cut on a line boundary and the reply says so.
- The hand-off text is built by the same formatters as the clipboard, so the preview and what leaves
  the plugin cannot drift apart.

## 1.0.0

First public release.

- Custom editor for `.xlsx` and `.xlsm` that draws what the file carries: fills, fonts, borders,
  alignment, number formats, merged cells, frozen panes, column widths and row heights, on every
  sheet.
- Editing: type a value, overwrite a cell, clear a selection, paste a block of text, undo and redo.
  Numbers, text, booleans, formulas, dates and error values round-trip with their type.
- Saving rewrites only the cells that changed inside the sheets that changed. Every other part of
  the package — styles, shared strings, drawings, charts, macros, pivot caches — keeps its exact
  compressed bytes, so a workbook with a macro project opens and saves without touching it.
- Copy the selection as TSV, CSV or a Markdown table, and export a whole sheet to a file.
- Read-only documents, outside writes and refusals by the writer are reported instead of being
  quietly ignored; an edit the writer cannot take never blocks the rest of the save.
