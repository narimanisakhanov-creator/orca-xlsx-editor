# Скриншоты

Снимок в README — не мокап. Он получен штатной командой Orca:

```sh
orca plugin shot local.xlsx-editor --editor ./test/fixtures/styled.xlsx --out ./docs/images/styled-workbook.png --json
```

Источник — синтетическая книга `test/fixtures/styled.xlsx`, которую тесты используют для проверки чтения форматирования и отображения. Команда открывает собранный custom editor в Orca и сохраняет фактический кадр интерфейса в PNG; в снимке видны заливка заголовка, чередующиеся строки, границы, числовые форматы и закреплённая область. Это не изображение, собранное вручную и не UI-мокап.

Дополнительный пример из пакета — [скриншот редактора](../images/screenshot.png). Обложка плагина — [cover.png](../images/cover.png).

## Воспроизведение

Из корня репозитория:

```sh
npm ci
npm run build
orca plugin dev load .
```

После загрузки dev-папки выполните команду `orca plugin shot` выше. Путь `--editor` указывает на книгу, а `--out` — на создаваемый PNG. Синтетическая книга уже находится в `test/fixtures/`, поэтому внешний файл и сеть не нужны.
