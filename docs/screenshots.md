# Скриншоты

Снимок в README — не мокап. Он получен штатной командой Orca:

```sh
orca plugin shot local.xlsx-editor --editor ./test/fixtures/styled.xlsx --out ./docs/images/styled-workbook.png --json
```

Источник — синтетическая книга `test/fixtures/styled.xlsx`, которую тесты используют для проверки чтения форматирования и отображения. Книга не лежит в репозитории (в публичном репозитории плагина нет бинарных файлов), её собирает `test/helpers/build-fixtures.mjs`; команда открывает собранный custom editor в Orca и сохраняет фактический кадр интерфейса в PNG; в снимке видны заливка заголовка, чередующиеся строки, границы, числовые форматы и закреплённая область. Это не изображение, собранное вручную и не UI-мокап.

Дополнительный пример из пакета — [скриншот редактора](../images/screenshot.png). Обложка плагина — [cover.png](../images/cover.png).

## Воспроизведение

Из корня репозитория:

```sh
npm ci
npm run build
node test/helpers/build-fixtures.mjs
orca plugin dev load .
```

После загрузки dev-папки выполните команду `orca plugin shot` выше. Путь `--editor` указывает на книгу, а `--out` — на создаваемый PNG. Сборка книг локальна и без сети; `npm test` создаёт те же файлы сам, так что отдельный шаг нужен только для снимка.
